# InstantMiseryMod

A MelonLoader mod for The Long Dark that allows customization of the Misery game mode.

## Features
- **Enable Instant Misery**: Applies all 6 misery afflictions on spawn.
- **Allow Sleep Healing with Broken Body**: Heal during sleep (note that all other healing restrictions and the double damage from Broken Body still apply).

## Design Philosophy

This mod is designed to create a more intense early-game challenge while making long-term survival actually viable:
* **Brutal Start**: Enforcing all 6 afflictions from day one makes the beginning of your run much more difficult.
* **Indefinite Play**: By allowing healing *only* during sleep (all other healing items and passive health regeneration sources are still blocked), you can theoretically survive indefinitely. This removes the hard cap of the standard "no healing" mechanic—which can feel like a timer rather than a challenge—while keeping the double-damage threat active.

## Installation
1. Install MelonLoader.
2. Download `InstantMiseryMod.dll` from the `Releases` folder in this repository.
3. Place `InstantMiseryMod.dll` in your game's `Mods` folder.
